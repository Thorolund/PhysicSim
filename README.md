# Название проекта (физический симулятор)

> Симуляция физики с использованием Box2D и визуализацией на SDL2.

## Описание
Проект представляет собой физический симулятор на базе Box2D 2.4.1 с графическим интерфейсом на SDL2. Предназначен для моделирования динамики твёрдых тел, взаимодействий и столкновений.

### Force
**Зависимости:** box2d

**Содержание:**
- `class Force` — описание силы для приложения к телу
  - **Атрибуты:**
    - `name` — идентификатор силы
    - `isLocal` — true — сила действует на одно тело, false — на все тела симуляции
    - `fVec` — вектор силы
    - `pointAttach` — точка приложения силы (в локальных координатах тела)
  - **Методы:**
    - `Force()` — конструктор по умолчанию (нулевая сила)
    - `Force()` — конструктор с параметрами
    - `GetName()` — возвращает имя силы


### ParameterizeBody
**Зависимости:** box2d, Force.h, logger.h

**Содержание:**
- `class ParamBody` — обёртка над b2Body с управлением силами и вычислением ускорений
  - **Атрибуты:**
    - `name` — имя тела
    - `permanentForces` — карта постоянных сил (пользовательские)
    - `instantForces` — карта мгновенных сил (возникают во время симуляции)
    - `prevAV` — предыдущая угловая скорость
    - `totalForce` — суммарная сила (permanent + instant)
    - `world` — указатель на мир Box2D
    - `body` — указатель на тело Box2D
  - **Методы:**
    - `ParamBody()` — конструктор, создаёт тело с фикстурами
    - `~ParamBody()` — деструктор, удаляет тело и очищает силы
    - `GetName()` — возвращает имя тела
    - `isForceInPermanent()` — проверка наличия силы в permanent
    - `isForceInInstant()` — проверка наличия силы в instant
    - `GetForceByName()` — получение силы по имени
    - `GetTotalForce()` — получение суммарной силы
    - `GetListPermanentForces()` — получение списка постоянных сил
    - `GetListInstantForces()` — получение списка мгновенных сил
    - `ApplyPermanentForces()` — применение всех постоянных сил
    - `AddPermanentForce()` — добавление постоянной силы
    - `AddInstantForce()` — добавление мгновенной силы
    - `AddVelosity()` — добавление импульса скорости
    - `DeleteForceByName()` — удаление силы по имени
    - `ClearInstantForces()` — очистка всех мгновенных сил
    - `Update()` — обновление состояния (суммарная сила, угловая скорость)
    - `CountAngularAceleration()` — вычисление углового ускорения
    - `CountLinearAcceleration()` — вычисление линейного ускорения
  - **Приватные методы:**
    - `UpdateTotalForces()` — пересчёт суммарной силы
    - `UpdatePrevAV()` — обновление сохранённой угловой скорости
