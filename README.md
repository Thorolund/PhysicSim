## Назначение фильтров/файлов
### main.cpp
`main.cpp` - файл точки входа в приложение.
Содержит <b>единственню</b> функцию
* Подключения файлов/библиотек:
    - 1
    - 2
* Классы
* Функции
    - `int main(int argc, char* argv[])` - функция входа в приложения.
    Единственная функция `main.cpp`.
    Не должна содержать прямую реализацию какого-либо самостоятельного участка программы,
    исключительно вызов основных функций.
### Math
Фильтр `Math` - группа файлов,
содержащих объявление/реализацию
математических объектов вне `cmath` и операций с ними.
### Класс `vec` — двумерный вектор

**Назначение:**  
Геометрический вектор с координатами (x, y) типа float. Хранит предвычисленную длину для оптимизации.

**Особенности:**
- Арифметические операции: +, -, * (скаляр), / (скаляр), скалярное произведение
- Предвычисление длины в конструкторе
- Нормализация с проверкой на нулевой вектор
- Левая и правая нормали (поворот на ±90°)
- Геттеры с приведением к int

**Зависимости:**  
`logger.h` — логирование ошибок (деление на ноль, нормализация нулевого вектора).

**Файлы:**
`vec.h` - объявление, `vec.cpp` - реализация.
