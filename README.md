## Назначение фильтров/файлов

`main.cpp` - файл точки входа в приложение.
Содержит <b>единственню</b> функцию
* Подключения файлов/библиотек:

    - 2
* Классы
* Функции
    - `int main(int argc, char* argv[])` - функция входа в приложения.
    Единственная функция `main.cpp`.
    Не должна содержать прямую реализацию какого-либо самостоятельного участка программы,
    исключительно вызов основных функций.
### Math
Фильтр `Math` - группа файлов,
содержащих объявление/реализацию
математических объектов вне `cmath` и операций с ними.
#### `vec.h` и `vec.cpp`
`vec.h` - объявление структуры математического вектора.
`vec.cpp` - реализация объявленных функций
* Подключения файлов/библиотек:
    - `<cmath>`
    - `"logger.h"`
* Классы:
    - struct `vec`
        - Атрибуты:
            - `float x` - координата по Ox
            - `float y` - координата по Oy
        - Методы:
            - `vec(float x_ = 0, float y_ = 0)` - конструктор `vec`.
            Задаёт координаты `x`, `y` - числа с плавающей точкой.
            - `int xint()`, `int yint()` - выдает координаты
            (`x`/`y`) как целого числа.
            - `vec sum(vec other_vec)` - складывает vec `this` с vec `other`.
            Создает новый `vec`.
            - `vec sub(vec other_vec)` - вычитает `vec other` из `vec this`.
            Создает новый `vec`.
            - `vec mlt(float a)` - умножает `vec this` на число `a`.
            Создает новый `vec`.
            - `vec div(float a)` - делит `vec this` на число `a`.
            Создает новый `vec`. Содержит исключение.
            - `float scalmlt(vec other_vec)` - скалярно умножает
            `vec this` на `vec other`.
            - `float len()` - возвращает длину `vec this`.
            - `vec len1()` - приводит `vec this` к единичной длине.
            - `vec rnormal()` - создает `vec normal`,
            равный по длине `vec this` и правоориентированный.
            - `vec lnormal()` - создает `vec normal`,
            равный по длине `vec this` и левоориентированный.
