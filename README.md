# Название проекта (физический симулятор)

> Симуляция физики с использованием Box2D и визуализацией на SDL2.

## Описание
Проект представляет собой физический симулятор на базе Box2D 2.4.1 с графическим интерфейсом на SDL2. Предназначен для моделирования динамики твёрдых тел, взаимодействий и столкновений.

### ParameterizeBody
**Зависимости:** box2d, logger.h

**Содержание:**
- `class ParamBody` — обёртка над b2Body
  - **Атрибуты:**
    - `prevLV` — предыдущая линейная скорость
    - `prevAV` — предыдущая угловая скорость
    - `world` — указатель на мир Box2D
    - `body` — указатель на тело Box2D
    - `name` — идентификатор объекта
  - **Методы:**
    - `ParamBody()` — конструктор, создаёт тело
    - `~ParamBody()` — деструктор, удаляет тело из мира
    - `AddFixture()` — добавление фикстуры к телу
    - `GetName()` — возвращает имя тела
    - `CountLinearAcceleration()` — вычисление линейного ускорения
    - `CountAngleAcceleration()` — вычисление углового ускорения
    - `UpdatePrevVelocites()` — обновление сохранённых скоростей


### Force
**Зависимости:** box2d

**Содержание:**
- `class Force` — описание силы для приложения к телу
  - **Атрибуты:**
    - `name` — идентификатор силы
    - `isLocal` — true — сила действует на одно тело, false — на все тела симуляции
    - `fVec` — вектор силы
    - `pointAttach` — точка приложения силы (в локальных координатах тела)
  - **Методы:**
    - `Force()` — конструктор, создаёт силу с вектором, флагом типа, именем и точкой приложения
    - `GetName()` — возвращает имя силы



### BodyForce
**Зависимости:** ParameterizeBody.h, Force.h, logger.h

**Содержание:**
- `class BodyForce` — связка между телом и силой
  - **Атрибуты:**
    - `bodyPtr` — указатель на тело
    - `forcePtr` — указатель на силу
  - **Методы:**
    - `BodyForce()` — конструктор, привязывает силу к телу
    - `GetForce()` — возвращает указатель на силу
    - `GetBody()` — возвращает указатель на тело
    - `ApplyForce()` — применяет силу к телу в точке приложения
