# Название проекта (физический симулятор)

> Симуляция физики с использованием Box2D и визуализацией на SDL2.

## Описание
Проект представляет собой физический симулятор на базе Box2D 2.4.1 с графическим интерфейсом на SDL2. Предназначен для моделирования динамики твёрдых тел, взаимодействий и столкновений.

## Особенности
- Физический движок Box2D 2.4.1 (тела, связи, коллизии)
- Визуализация на SDL2 (SDL2, SDL2_image, SDL2_ttf)
- Модульная архитектура
- Система логирования
- Гибкий интерфейс пользователя (в разработке)

## Требования
- Компилятор с поддержкой C++17/20
- Box2D 2.4.1
- SDL2, SDL2_image, SDL2_ttf
- Стандартная библиотека C++
