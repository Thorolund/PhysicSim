### Класс `vec` — двумерный вектор

**Назначение:**  
Геометрический вектор с координатами (x, y) типа float. Хранит предвычисленную длину для оптимизации.

**Особенности:**
- Арифметические операции: +, -, * (скаляр), / (скаляр), скалярное произведение
- Предвычисление длины в конструкторе
- Нормализация с проверкой на нулевой вектор
- Левая и правая нормали (поворот на ±90°)
- Геттеры с приведением к int

**Зависимости:**  
`logger.h` — логирование ошибок (деление на ноль, нормализация нулевого вектора).

**Файлы:**
`vec.h` - объявление, `vec.cpp` - реализация.

## Физический модуль (Physic)

### Класс `PhysPoint` — физическая точка

**Назначение:**  
Материальная точка с тройным буфером позиций для динамической симуляции.

**Особенности:**
- Три состояния позиции: ppos (предыдущая), cpos (текущая), npos (следующая)
- Накопление ускорений в векторе
- Флаг `stabled` — закреплённая точка
- `set_new_pos()` — обновление позиции по схеме Верле (только для подвижных точек)
- `move_to()` — принудительное перемещение всех позиций (для stabled в т.ч.)
- Автокоррекция массы (min 0.01)

**Зависимости:**  
`vec.h`, `logger.h`

**Файлы:**
`physpoint.h` - объявление, `physpoint.cpp` - реализация.

### Класс `PhysEdge` — ребро между двумя физическими точками

**Назначение:**  
Связь между двумя точками, поддерживающая фиксированное расстояние (растяжение/сжатие). Используется для построения конструкций.

**Особенности:**
- Хранение указателей на две точки
- Кэширование вектора и длины ребра
- `update()` — пересчёт текущего состояния
- `shrink()` — коррекция позиций точек для восстановления базовой длины
- Учёт масс точек при распределении поправки
- Поддержка закреплённых точек (stabled)

**Файлы:**
`physedge.h` - объявление, `physedge.cpp` - реализация.
